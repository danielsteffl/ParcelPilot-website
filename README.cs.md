# ParcelPilot 📦

Fiktivní webová stránka pro logistickou a doručovací službu vytvořená jako osobní projekt.

Web se vyznačuje minimalistickým světlým designem s červenými brandovými akcenty, responzivním rozvržením, sledováním zásilek, kalkulačkou ceny přepravy, návodem krok za krokem, zákaznickými recenzemi a sekcí pro stažení fiktivní mobilní aplikace.

> **Upozornění:** Jedná se o fiktivní projekt vytvořený pouze pro vzdělávací a portfoliové účely. Nereprezentuje reálnou společnost ani logistickou firmu. Všechny firemní údaje, kódy pro sledování, kontakty i služby jsou pouze ilustrační.

## Funkce a vlastnosti

- **Responzivní design** — Rozvržení plně přizpůsobené pro desktop, tablety i mobilní zařízení.
- **Moderní UI** — Minimalistický vzhled s červenými akcenty (#D0192E).
- **Sledování zásilek** — Interaktivní karta sledování s podporou ukázkových kódů (`PP-1001-CZ`, `PP-2002-CZ`) a vizuální časovou osou stavu doručení.
- **Kalkulačka přepravy** — Nástroj pro výpočet ceny a času doručení na základě trasy, hmotnosti a typu přepravy.
- **Jak to funguje** — Přehledný 3krokový vizuální návod popisující proces odeslání balíku.
- **Zákaznické recenze** — Sekce se zkušenostmi a hodnocením od zákazníků.
- **Sekce ke stažení aplikace** — Promo sekce s mobilní aplikací pro iOS a Android včetně tlačítek obchodů.
- **Mobilní navigace** — Responzivní rozbalovací menu pro menší obrazovky.
