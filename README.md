# ParcelPilot 📦

A fictional logistics and delivery service website created as a personal practice project.

The website features minimalist light design with brand red accents, responsive layouts, parcel tracking, a shipping price calculator, a step-by-step guide, customer reviews, and a mobile fictional app download section.

> **Disclaimer:** This is a fictional project created for educational and portfolio purposes only. It does not represent a real business or logistics company. All business details, tracking codes, contacts, and services are illustrative.

## Features

- **Responsive Design** — Layout adapted for desktop, tablet, and mobile devices.
- **Modern UI** — Minimalist design with red accents (#D0192E).
- **Parcel Tracking** — Interactive tracking card with sample code support (`PP-1001-CZ`, `PP-2002-CZ`) and with a visual status timeline.
- **Shipping Calculator** — Calculator tool for delivery price and times based on routes, weight, and delivery types.
- **How It Works** — Clear 3 step visual timeline explaining the shipping process.
- **Customer Reviews** — Testimonials showcasing customer feedback.
- **App Download Section** — Promo section with mobile app for iOS and Android with store buttons.
- **Mobile Navigation** — Responsive mobile menu toggle for smaller screens.

## Built With

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript, json
